# MERIT-CORE

## About the Project

MERIT-CORE is a web application developed by Group 3 — Databloom Africa. This repository contains the frontend and backend components of the project.

## Project Structure

- `frontend/` — Frontend application.
- `backend/` — Backend server and API.

## Technologies

The project uses the following technologies:

- **Frontend:** React
- **Backend:** Node.js and Express
- **Database:** PostgreSQL

## Getting Started

### Prerequisites

Before running the project, ensure you have installed:

- Node.js and npm
- PostgreSQL or access to the configured PostgreSQL database

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Group3-DatabloomAfrica/MERIT-CORE.git
   cd MERIT-CORE
   ```

2. Install the backend dependencies:

   ```bash
   cd backend
   npm install
   ```

3. Configure the backend environment variables in a local `.env` file using the project's required settings. **Do not commit secrets or credentials to GitHub.**

4. Start the backend using the configured start script:

   ```bash
   npm start
   ```

5. Open a second terminal, navigate to the frontend directory, install its dependencies, and start it using the scripts defined in `frontend/package.json`.
